# Changelog

## 0.1.1 — 2026-08-02

- Systémové TTS bylo nahrazeno výhradně lokálním OmniVoice backendem.
- Přidána oddělená voice-design služba, barge-in `/stop`, diagnostika a launchd helper.
- Doplněna CC-BY-NC informace k modelu; modely a hlasová data se stále nebalí.
- Přidány úplné polské, slovenské, německé, maďarské a bulharské návody;
  dokumentace nyní obsahuje češtinu a 20 úplných překladů.

## 0.1.0 — 2026-08-02

- První veřejný zdrojový release pro macOS Apple Silicon.
- Lokální český Whisper/Ollama runtime, paměť, dashboard a overlay.
- Opt-in research, hlasový otisk a read-only terminál.
- Privátní konfigurace/data, launchd CLI, bezpečný tuner a sanitizační brány.
